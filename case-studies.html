03 · Built in-houseOur own product

Magniscan

A security scanning SaaS, built in-house by Kliks.

What we built
A security scanning SaaS for citizen developers, solo founders and makers who built their app with AI tools like Lovable, Bolt or Replit and have no idea what vulnerabilities they may have accidentally shipped.
The details
A free passive scan, no login needed, plus a deep active scan powered by OWASP ZAP, checking for exposed API keys, database credentials, open server ports, malware flags and data breaches. Every finding gets translated into plain English with a paste-ready fix prompt for whatever AI coding assistant built the app in the first place.
The build
Built end-to-end in a matter of weeks. Stripe billing, domain verification, async scan architecture and a shareable results page, a fully featured SaaS product shipped at speed without a traditional engineering team.

04 · Built in-houseOur own product

Occasionly

A self-serve SaaS for occasion-driven retailers, built in-house by Kliks.

What we built
A self-serve SaaS for occasion-driven retailers such as bakers, florists and gift shops. It saves the birthdays and anniversaries customers shop for, then sends a branded reminder before each date so they reorder in time.
The details
An embeddable, white-label widget, a daily reminder engine, a merchant dashboard with revenue tracking, custom sender domains and an Omnisend integration in private beta.
The build
Built and launched as a multi-tenant product on Next.js, TypeScript and Supabase (Postgres with row level security), with Stripe billing, Resend for email and Vercel for hosting.
